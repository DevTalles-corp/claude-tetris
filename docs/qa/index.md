# Índice de QA

Documentación del flujo de pruebas de Tetris. Empieza por el ciclo, después revisa cada fase.

Para pedir un cambio, crea el issue con la plantilla **Requerimiento** (*New issue → Requerimiento*). Claude lo diagnostica y etiqueta al crearlo; la implementación se pide después mencionándolo en un comentario.
